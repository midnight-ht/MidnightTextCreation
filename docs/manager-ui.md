# 本机内容工作台

管理页由本机管理服务提供，打开服务根地址即可使用。服务端口可配置；前端使用当前页面 origin，不固定 8765。先创建账号、风格和平台绑定，再生成或导入内容。所有 ID 使用字母、数字、下划线或短横线。

## 配置与版本

简单表单编辑保留已有高级字段；完整 JSON 页可查看、修改和导入配置。导入文件先预览，点击“校验并保存”才写入。删除正在使用的账号或风格会被服务端引用校验阻止。修改 ID 会创建新记录；需要删除旧记录时单独操作。

绑定选择 mock、browser 或 api。mock 明确标注模拟；真实平台浏览器选择器与 API 权限需现场核验。样文、审稿配置及 API 响应映射可在完整 JSON 中扩展。不得保存密码、Cookie、Token；API 适配器使用 `token_env` 引用本机环境变量。

浏览器适配器在绑定的 `adapter` 中设置 `editor_url`、`collector_url`、`selectors`（account/title/body/summary/tags/content_id/status/metrics）与 `status_mapping`。选择器必须唯一匹配。API 适配器设置 `endpoint`（可含 `{content_id}`）、`token_env` 和 `status_mapping`。例如把平台的原始审核值映射到 processing/published/rejected/removed。缺失指标保留 null。

内容生成接收输入参数 JSON 和单次覆盖 JSON；导入接收完整 publication JSON，保留 media 及其他模型输出字段。界面不授予人工审批或发布状态。关联真实发布 ID、链接与实际发布时间后，可以立即回收或设置默认 60 秒轮询。

## 浏览器助手

在已安装 browser-helper 的浏览器中打开管理页。“打开并填充”创建任务，通过同源 window 消息交给扩展，扩展打开编辑页、核对账号、写入并回读。只有 filled 回执成功记录后界面才显示填充完成。25 秒无响应会记录失败，提示安装助手并刷新页面。选择器错误、非空草稿、错账号、缺素材等保留明确错误，不自动覆盖草稿。

mock-editor.html 是独立模拟页面，账号和内容 ID 来自 URL，安全写入 textContent；默认正文为空，阅读数留空表示不可用，没有发布按钮。使用真实 browser-helper 可验收模拟填充链路；模拟验收不证明真实三平台可用。

状态卡分开显示最近查询结果、观测时间、上次成功、来源与新鲜度。失败查询不把缓存显示成最新成功；轮询由本机服务管理。浏览器回收需要可见管理页与已授权会话；浏览器轮询仅管理页可见且未编辑时执行，按设置间隔打开页面核验；查询失败指数退避，最长 3600 秒（设置间隔更长时遵循该间隔），停止后不再创建查询，已发出的任务可以完成。API/mock 轮询由服务后台执行，界面每 5 秒刷新；正在编辑表单或页面隐藏时暂停界面刷新与浏览器轮询。

## 验证

`node --test tests/test_manager_ui.cjs` 检查高级配置保留、失败状态与旧成功区别、完整 publication 导入及跨来源消息拒绝。`node --check manager/app.js` 检查语法。真实平台、浏览器助手和桌面目录打开仍需运行验收。
