# 文章、软文、图文、视频生成方式调研

调研日期：2026-10-04。

范围：可用于当前 midnight-advertorial skill 的创作流程、工具路线、交付物、审核及升级顺序。依据公开官方资料与当前本地文件；没有运行付费生成、模型对比、真实发布或流量实验。“主流”在这里指常见产品支持的生产路线，不代表经统计验证的市场份额排名。

## 一、结论

建议采用“统一事实素材包 + 分类型创作 + 分类型制作 + 成品审核”，而不是用一个提示词同时交付所有形式。

文章需要可靠论证；软文需要可验证的商业声明和披露；图文需要实际图像与可读排版；视频需要实际音画、时间轴和成片。它们可以共享主题与证据，但不能把长文分句后就声称已经交付图文或视频。

优先级建议：先补软文的商业审核及图文实际渲染，再做模板视频，最后按需要接入生成式镜头。此排序是针对当前项目已有文案流程、尚缺媒体制作能力的工程判断，不是行业效果排名。

## 二、文章生成

### 路线对比

| 路线 | 输入与过程 | 适用内容 | 主要风险 |
| --- | --- | --- | --- |
| 单次提示词 | 主题、受众、素材、风格 → 草稿 | 低风险短稿、内部头脑风暴 | 容易补不存在的事实，结果不稳定 |
| 素材驱动 | 来源整理 → 事实表 → 大纲 → 分节写作 → 核查 | 专业文章、方法论、产品知识 | 检索结果仍可能过时或不能支持结论 |
| 多候选编辑 | 不同角度及开头 → 按证据与受众比较 → 选定后成文 | 同一事实可从多角度解释的内容 | 只比较标题刺激度会放大标题党 |
| 生成与评审循环 | 初稿 → 独立标准审稿 → 局部修订 → 有上限复审 | 有明确质量标准的正式稿 | 同一模型复审不是独立事实验证 |
| 访谈转写 | 真实访谈/录音 → 转写 → 主张与出处 → 成文 → 当事人确认 | 作者经验、专家访谈、案例 | 语音识别错误、断章取义、隐私与授权 |

分步提示链、任务路由、生成与评审循环均有公开工作流依据；Anthropic 建议从满足任务的简单方案开始，只有确有收益才增加复杂度。[工作流模式与取舍](https://www.anthropic.com/engineering/building-effective-agents)

### 推荐执行流程

1. 定义受众、问题、核心判断、时效范围与发布平台。
2. 把素材区分为事实、作者意见、真实经历、第三方观点和待核实信息。
3. 每个事实记录来源、日期、适用条件；重要结论检查原始来源，不能只看搜索摘要。
4. 产出少量有差异的角度与开头，比较准确性、可兑现承诺和读者价值。
5. 大纲中每节指定“要推进的判断、使用的证据、保留的限制”。
6. 成文后核对事实、数字、引语、因果推断、作者风格及完整论证。
7. 平台适配后再查实际标题、封面和正文，防止为了传播删掉边界。

交付：正文、标题候选及选定标题、导读、来源表、待核实项、修改记录、平台版本。

使用检索或知识库是为了提供证据，不是自动保证正确；输入来源与“经过核验的来源”必须分开记录。当前 skill 的 facts 字段目前是用户提供的来源，并未独立验证。

## 三、软文生成

软文不是“把广告写得看不出来”，而是用对读者有价值的内容介绍真实商品或服务，并保留必要商业披露。

### 可采用的内容结构

| 形式 | 内容顺序 | 必要输入 | 禁止补造的内容 |
| --- | --- | --- | --- |
| 场景解决方案 | 场景 → 问题 → 选择标准 → 产品如何满足 → 不适用情况 → 行动 | 功能、条件、价格日期、使用场景 | 虚构痛点调查或效果承诺 |
| 真实体验 | 实际背景 → 使用过程 → 观察 → 优缺点 → 适用人群 | 真实试用记录、截图、授权 | 没试用却写“我用了一个月” |
| 客户案例 | 客户约束 → 实施 → 有依据的结果 → 其他影响因素 → 边界 | 当事人同意、结果数据、观察窗口 | 假客户、假评价、无依据的增长率 |
| 对比选购 | 比较维度 → 同条件证据 → 取舍 → 人群匹配 | 对比对象、版本、日期、方法 | 捏造竞品缺陷或不同口径对比 |
| 品牌故事 | 可核查起点 → 决策 → 产品原则 → 证据 | 真实人物、事件、素材与授权 | 虚构创始人经历和媒体背书 |

这些结构是本次提出的编辑方法，不是效果保证；不能用某种结构代替证据。

### 商业事实包与审核

建议新增：广告主/品牌、商品、商业关系、允许声明、证据材料、价格有效期、适用地区、禁止声明、购买路径、披露文字与位置、需人工审批的行业。

审核每条“卖点 → 证据 → 限制 → 披露”。比如“节省一半时间”必须有测试方法、样本和比较条件；没有证据则改为准确功能说明，不能只降低措辞后保留暗示。

中国《互联网广告管理办法》第九条要求广告具有可识别性；其中，知识介绍、体验分享、消费测评等推销并附加购物链接等购买方式的情形，应显著标明广告。第七、八条还规定了特定行业广告审查及变相发布限制；加标识不是对禁止内容的豁免。[市场监管总局原文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_d93a579afd45413e8576e4623fab348f.html)

面向美国受众的推广，FTC 指南强调对可能影响推荐可信度的品牌关联作清楚、显著披露，不能假定平台内置工具必然充分。其他国家须单独查当地要求，不能把美国规则推广为全球统一规则。[FTC 指南](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides-what-people-are-asking)

交付：内容稿、商业声明证据表、披露方案、适用与不适用条件、来源及购买路径检查记录。法律问题须由适当专业人员复核，模型评分不等于合规批准。

## 四、图文生成

图文包括“文章配图”和“多页社交卡片”；后一种还需要页间信息顺序和一致的视觉规则。

| 路线 | 制作方法 | 适用场景 | 取舍 |
| --- | --- | --- | --- |
| 真实照片/截图 + 排版 | 选有授权素材 → 核对内容 → 裁切 → 图注/文字层 | 产品、教程、评测、案例 | 真实性好，但依赖素材质量 |
| 文生图/参考图编辑 | 视觉任务 → 主体、场景和构图 → 候选 → 审核 → 后期文字层 | 封面、解释插画、非事实场景 | 需要检查错字、主体失真、一致性和误导 |
| 固定模板渲染 | 卡片结构化数据 → 模板 → 导出 → 可读性检查 | 清单、知识卡片、系列内容 | 版式可控，但要避免模板化内容 |
| 混合生产 | 生成/真实素材 + 确定性文字与图表 + 模板 | 大多数系列图文 | 多一步制作，但便于控制事实与字号 |

Canva Magic Design 支持社交内容等设计类型，可用作可编辑的设计起点；这不意味着所有品牌、文字和平台裁切自动合格。[Canva 官方介绍](https://www.canva.com/magic-design/)

Runway 的图像工具支持图像参考和迭代，用于控制角色或场景；参考能力不等于最终产品细节和跨页一致性已经验收。[Runway 图像创作指南](https://help.runwayml.com/hc/en-us/articles/37053594806419-Creating-with-Gen-4-Image)

### 推荐流程

1. 卡片内容规划：每页说明读者要获得什么，不以固定页数凑内容。
2. 视觉说明：画幅、层级、字号策略、色彩、参考图、可用素材与禁用元素。
3. 素材获取：事实性图片优先真实授权素材；生成插画不得冒充真实事件或实测截图。
4. 制作：生成背景或插画；关键文字、价格、图表和免责声明优先用可控文字层叠加。这是控制可读性和数据一致性的工程建议，并非宣称所有图像模型不能写文字。
5. 验收：逐页核对文字与事实、溢出/裁切、对比度、来源、图片权利及必要说明。
6. 导出：实际图片、封面、说明文案、页序与素材记录；在目标平台手机预览。

交付至少要有实际 PNG/JPEG 等图像，而不仅是提示词或卡片文本。OCR 可辅助核对，但不能代替视觉检查；商品外观、标志和事实图表尤其需要人工确认。

## 五、视频生成

### 可行路线

| 路线 | 过程 | 适用场景 | 主要风险/成本来源 |
| --- | --- | --- | --- |
| 实拍 + AI 辅助剪辑 | 脚本 → 拍摄 → 剪辑 → 字幕 → 复核 | 真人经验、产品演示、纪实 | 拍摄成本、授权、声音和画面质量 |
| 图文/录屏 + 配音 + 模板 | 审定脚本 → 图片/录屏 → 配音 → 真实时间轴 → 合成 | 知识、教程、清单、产品解释 | 容易单调，字幕和镜头需配合内容 |
| 文生视频 | 镜头说明 → 候选短片 → 选择 → 剪辑 | 创意气氛、虚构场景、辅助镜头 | 一致性、动作、重试成本、虚构真实性 |
| 图生视频/首尾帧 | 审定画面 → 动作/运镜说明 → 生成 → 检查 | 主体较明确的创意镜头 | 运动失真，主体细节可能变化 |
| 参考生视频/视频编辑 | 参考素材 → 生成或局部变更 → 连续性审核 | 有既定视觉和素材的制作 | 权利、人物授权、时序和模型限制 |
| 数字人口播 | 授权形象与声音 → 脚本 → 生成 → 同步与标识审核 | 经授权的讲解场景 | 不得伪装真人背书；肖像、声音、商用条件需审核 |

阿里云百炼官方视频能力目录区分文生、图生、首尾帧、参考生、视频编辑及数字人等路径；可用输入、地区和输出能力取决于具体模型。火山引擎即梦也有首尾帧图生视频文档。这里只核验路线存在，不作最新模型性能排名或统一价格承诺。[百炼能力目录](https://help.aliyun.com/zh/model-studio/video-generate-edit-model/)、[即梦首尾帧文档](https://www.volcengine.com/docs/85621/1791184?lang=zh)

Runway 的图生视频指南把输入图像用于确定构图、主体、光线和风格，而提示词重点描述动作、运镜和时间变化。因此，适合先审定关键帧，再逐镜头生成，而不是把整篇长文直接当视频提示词。[Runway 图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)

Remotion 支持将参数化模板和素材渲染为视频文件，适合可控的图文动画、录屏包装和批量系列内容；字幕工具支持导入/转写后的字幕及展示、导出。它是程序化制作工具，不是自动产生真实镜头或正确事实的模型。[Remotion 服务端渲染](https://www.remotion.dev/docs/ssr)、[字幕文档](https://www.remotion.dev/docs/captions/)

### 推荐流程

1. 审定脚本：每个镜头单元有讲述目的、口播、画面需求和对应事实。
2. 选择制作路线：真实演示用实拍/录屏；解释型内容用模板；创意镜头再考虑生成模型。
3. 准备镜头：真实素材记录来源；生成素材记录输入、模型、版本、授权与重试。
4. 生成或录制配音：确认声音权利、读音、数字和自然停顿。
5. 测量真实音频/视频时长并转写或对齐字幕；脚本阶段只能给预算，不能假造字幕时间戳。
6. 合成并混音：安排画面与语义对应，处理转场、字幕、安全区、配乐与来源说明。
7. 看完整成片：画面异常、主体连续性、文字、事实、口型、音画同步、节奏、版权及标识。
8. 导出 MP4、封面、字幕文件与发布包；不同画幅重新预览，不能只机械裁切。

成本不能只看每秒标价：还应计算失败和重试、废弃镜头、编辑、配音、素材、渲染及人工审核。本次未做计费试验，不能给出实测单片成本或最便宜供应商结论。

## 六、四类内容共用的控制

- 素材与证据：来源、日期、权利、允许用途、主张与证据关联；敏感信息先处理。
- 审核：事实、表达、风格、平台适配；软文另查商业声明和披露，媒体另查画面/声音/成片。
- 预算：候选数、修订次数、生成重试次数、费用上限；超限停止，不能无限自动循环。
- 状态：文案审定、素材已生成、文件已导出、媒体已检查、人工批准、已发布分别记录。
- 反馈：曝光、阅读/观看、收藏、评论、转化分别看；没有随机或可比较条件，不声称标题变更造成流量增长。

中国《人工智能生成合成内容标识办法》已自 2025-09-01 施行，规定生成合成内容标识和传播环节责任。具体产品与发布环节应核对适用要求；不得把“降低 AI 味”解释成隐藏来源、恶意删除或伪造标识。AI 标识与商业广告披露是两件事，不能相互替代。[网信办原文](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

## 八、建议升级顺序

1. 统一创作输入：新增内容类型、证据状态、商业关系、素材授权、交付规格、预算和审批要求。
2. 软文专用分支：商业事实包、声明证据核对、适用人群、不适用条件和披露审核；高风险内容保留人工门禁。
3. 图文制作 MVP：先用真实素材/可控模板导出图片，再接可选生图；检查全部页序、文字、裁切与来源。
4. 模板视频 MVP：审定脚本 + 真实素材或图文 + 配音 + 实测时间轴 + 字幕 + 实际 MP4；先验证一条完整制作链。
5. 可选生成镜头：接入一家供应商验证关键帧、动作与主体一致性，设置重试和费用上限；逐步扩展供应商，而非一开始全部接入。
6. 最终媒体审核与反馈：只有拿到并检查真实文件才标注“已生成成品”；发布与效果实验另行授权和记录。

验收建议：文章可追踪关键主张；软文商业声明有依据且披露可见；图文实际导出并逐页检查；视频实际可播放且核对音画与字幕。先做代表性样本试验，再决定供应商、模板和阈值。本次只完成调研与方案整理，未实施这些升级。
